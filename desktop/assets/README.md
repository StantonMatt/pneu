# Desktop icons

The bundled Google Material Symbols are licensed under the
[Apache License 2.0](../../android/MATERIAL_SYMBOLS_LICENSE).

`movie.svg` is Google's [Material Symbols Outlined movie icon](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/movie/materialsymbolsoutlined/movie_24px.svg),
weight 400, grade 0, optical size 24, unfilled. Its path is unchanged; the SVG
omits fixed width/height and uses black fill for Slint colorization, matching
the other symbols' `0 -960 960 960` viewBox and weight. Existing `image.svg`
and `description.svg` use the Rounded variant.

`wifi.svg` and `language.svg` are Google's Material Symbols Rounded
[wifi](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/wifi/materialsymbolsrounded/wifi_24px.svg)
and [language](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/language/materialsymbolsrounded/language_24px.svg)
icons, prepared the same way. So is the Rounded
[link](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/link/materialsymbolsrounded/link_24px.svg)
icon (`link.svg`).
